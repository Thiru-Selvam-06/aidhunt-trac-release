# Publication scope

Includes the preserved Android implementation, unit/instrumentation fixtures, Worker/Functions policies, Firestore Rules, build/dependency manifests, CI, source/test inventories, maintenance tools, original architecture and this handbook. Nothing here deploys.

Excluded and preserved locally: environment secrets, signing keys, Firebase live client configuration, private evidence snapshots/captures, generated builds/dependencies/caches, unrelated nested qodex checkout and unreviewed historical operational reports. They are not required for the synthetic demo. GitHub contains templates and secret binding names only. Do not commit plaintext credentials even for an all-files backup.

Existing key exposure in Git history is not erased by this current-tree cleanup. Separate rotation/history review is required.
